# OralScan 亲子口腔检查应用

在线访问：https://liujunjie1114-ben.github.io/oralscan-family-app/

来自用户提供的 Figma Make 导出源码。原始 React/Vite 项目保存在根目录，GitHub Pages 发布文件位于 docs/。

## 本地查看

直接打开 docs/index.html，或在 docs 目录启动静态 HTTP 服务。

## 更新线上页面

修改 public/oralscan.html 或 public/assets 后，同步复制到 docs/index.html 与 docs/assets，提交到 main 后 GitHub Pages 自动发布。

当前口腔分析使用源码自带的模拟模式；真实模型分析需要另行接入后端。
